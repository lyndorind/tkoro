# Code of Conduct

## Our Commitment

We are committed to maintaining a respectful, welcoming,
and collaborative environment for all contributors.

## Expected Behavior

Contributors are expected to:

- Communicate respectfully.
- Provide constructive feedback.
- Respect different opinions.
- Focus on technical improvements.
- Help maintain a positive development environment.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Insulting or offensive comments.
- Personal attacks.
- Publishing private information without permission.
- Deliberate disruption of project discussions.

## Reporting

Violations should be reported privately to the
repository maintainers using the contact method
specified by the project.

## Enforcement

Maintainers may remove inappropriate content,
restrict participation, or revoke access when necessary.
