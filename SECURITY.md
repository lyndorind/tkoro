
# Security Policy

## Supported Versions

The latest version of the project is supported.

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities
before they have been reviewed.

Report security issues privately to the repository
maintainer.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested solution, if available

## Security Updates

Confirmed vulnerabilities will be reviewed and addressed
according to their severity.
